# Data and interface attribution

Sample images are from **PneumoniaMNIST**, distributed by the MedMNIST authors under **CC BY 4.0**.

- Original distribution: https://medmnist.com/
- Data record: https://zenodo.org/records/10519652
- Dataset definition: https://github.com/MedMNIST/MedMNIST/blob/main/medmnist/info.py
- Yang et al., *MedMNIST v2 — A large-scale lightweight benchmark for 2D and 3D biomedical image classification*, Scientific Data (2023).
- Source data described by Kermany et al., *Identifying Medical Diagnoses and Treatable Diseases by Image-Based Deep Learning*, Cell (2018).

This website includes selected, unmodified 28×28 grayscale sample pixels as PNG files. Browser display enlargement does not modify model inputs. No original full-resolution images are supplied. The gallery includes deliberately selected errors, not a representative subset.

The architecture-exploration concept is inspired by Medical CNN Explainer (https://ml-health.roshchupkin.org/cnn_explainer.html) and CNN Explainer (https://poloclub.github.io/cnn-explainer/). All project code and styling were written for this project; no third-party implementation was copied.

The code license does not relicense dataset images, dependencies, or externally loaded fonts.
